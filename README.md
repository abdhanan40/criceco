# CricEco 🏏

CricEco is a smart cricket management and matchmaking platform designed to connect players, clubs, grounds, umpires, coaches, and organizers in one ecosystem.

## Key Features

- Player and Club Management
- Match Discovery and Scheduling
- Ground Booking
- Umpire Availability
- Player Statistics and Performance Tracking
- AI-Based Team Balancing
- Player Draft System
- Quick Match
- Live Scoring
- Player Marketplace
- Role-Based Dashboards

## Tech Stack

- Flutter
- Dart
- REST APIs
- Mobile-first UI/UX

## User Roles

- Player
- Club Owner
- Ground Owner
- Umpire
- Organizer
- Coach
